# 📊 Gerador de Sequência Numérica

Projeto desenvolvido como exercício prático durante o curso de desenvolvimento Front-End no **Senac Taubaté**.

O objetivo foi recriar um exercício de lógica de programação, originalmente feito em HTML/JS puro, utilizando **React** com componentização e gerenciamento de estado.

---

## 🚀 Demo

🔗 [Acessar projeto online](https://stelsol.github.io/react/)

---

## 💡 Funcionalidades

- O usuário informa um número inteiro positivo
- Ao clicar em **Gerar**, o sistema exibe todos os números de 0 até o número informado
- Interface responsiva e estilizada com Tailwind CSS

---

## 🛠️ Tecnologias Utilizadas

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- JavaScript (ES6+)

## ⚙️ Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/stelsol/react.git

# Entre na pasta do projeto
cd react/projeto_1

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
